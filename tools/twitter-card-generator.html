What this tool does

      

        

          X reads a small set of twitter: meta tags to decide how a shared link
          looks. Without them it falls back to your Open Graph tags, and if those are missing too it renders a bare URL with no image —
          which in a timeline is close to invisible. This tool writes the tags and mocks up the card beside the form so you can see the
          result before you ship it.
        

        

          Everything is assembled locally in your browser; nothing is uploaded. The limitation worth knowing is caching: X stores a
          card per URL, so if you fix your tags after the link has already been posted, the old card can keep appearing until you
          re-validate the URL with X's Card Validator. This tool cannot do that step for you.

Frequently asked questions

      

        

          What is the difference between summary and summary_large_image?
          

            summary renders a small square thumbnail to the left of the title, which suits a
            logo, a headshot or podcast cover art. summary_large_image renders a wide banner
            above the title, which suits a product shot, a chart or a blog header. Large-image cards consistently get more taps because
            the picture occupies far more of the timeline.
          

        

        

          Do I still need Open Graph tags if I have Twitter Card tags?
          

            Yes. X falls back to Open Graph when the twitter: tags are absent, but every other
            platform that reads Open Graph — Facebook, LinkedIn, WhatsApp, Slack, Discord — ignores
            twitter: tags entirely. Ship both blocks, and keep the two descriptions consistent
            so the same link never looks like two different pages depending on where it is shared.
          

        

        

          Why does my card show the wrong image or no image at all?
          

            Cards are cached per URL, so an old scrape keeps winning until you force a refresh with X's Card Validator. The other
            common causes are a relative image URL, an image over 5MB, and a format X does not accept. Use an absolute
            https URL to a JPG, PNG or WebP under 5MB, and re-validate after every change.
