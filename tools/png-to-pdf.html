    What this tool does

    This tool turns a set of PNG images into a single PDF, one image per page. PNG is the format screenshots, charts, diagrams and anything with sharp edges or transparency tends to arrive in, and it is embedded here as PNG rather than re-encoded as JPEG — so text in a screenshot stays crisp instead of picking up compression artefacts around every letter.

    As with the JPG version, the page order is explicit rather than inherited. Each image is listed with its position and can be moved up, moved down or removed before the PDF is built.

    How to use it

    1. Click the drop zone or drag your PNGs in. Add more in a second batch if you need to.
    2. Rearrange the page order list if the sequence is wrong, using the ↑ ↓ and × buttons.
    3. Choose A4, US Letter or fit the image, plus an orientation and margin.
    4. Press Create PDF and the document downloads immediately.

    Frequently asked questions

    Does converting to PDF lose quality?

    No. The PNG data is embedded into the PDF as-is, so nothing is re-compressed on the way in. What you see in the PDF is exactly the image you supplied.

    What happens to transparent areas?

    The PDF keeps the transparency, and on a page it reads as white. If you need a solid background, flatten the image first — otherwise the result will look correct on screen but may show the page behind it in some viewers.

    Can I add JPGs to the same document?

    Not on this page — it accepts PNG only, and rejects anything else with a message rather than quietly re-encoding it. Use Image to PDF if your images are a mix of both formats.
