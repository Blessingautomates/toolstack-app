    What this tool does

    This tool does what JPG to PDF and PNG to PDF do, for the common case where you have both — a photo of a signed page next to a screenshot of the form it belongs to, or a folder exported from a phone that is a mixture of the two.

    Each image is embedded in its own format rather than being converted to a single one: JPEGs stay JPEG, PNGs stay PNG. Converting everything to one format would either bloat the file or soften the screenshots, so instead the tool keeps whatever each image already had.

    The order is yours to set. Every image is listed with its position and can be moved or removed before the PDF is assembled.

    How to use it

    1. Drop your images onto the box, or click to choose them. JPG and PNG can be mixed freely, in any number of batches.
    2. Set the page order with the ↑ ↓ buttons, and use × to drop any image you do not want.
    3. Choose a page size — A4, US Letter, or "fit the image" for borderless pages exactly the size of each picture.
    4. Press Create PDF and the finished document downloads straight away.

    Frequently asked questions

    Is there a limit on how many images I can combine?

    No. Images are embedded one at a time, so memory use stays flat however many you add. A very large batch produces a correspondingly large PDF and takes longer to write.

    Does it matter what order I add them in?

    Not at all — the list is the source of truth, not the order the files arrived in. Add everything first, then put the sequence right before you press the button.

    Are my images uploaded anywhere?

    No. They are read by your browser and the PDF is assembled on your device. Nothing leaves your computer, so the tool keeps working even with no connection once the page has loaded.
