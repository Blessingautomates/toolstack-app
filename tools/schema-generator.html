What this tool does

      

        

          Structured data is a small block of JSON that tells a search engine what a page is about in
          terms it can act on: this is a company, this is a product with this price, this person wrote
          this. This tool builds that block as JSON-LD, the format Google recommends, for the six page
          types it supports with rich results — Organization, WebSite, WebPage, Person, Service and
          Product.
        

        

          Two warnings, because this is an area where it is easy to waste effort. Schema markup does
          not improve rankings: it makes a page eligible for a richer result, which can earn
          more clicks at the same position, and that is a different thing. And markup must describe what
          is actually on the page. Describing a 4.9-star rating that no visitor can see is a
          structured-data guidelines violation, and Google issues manual actions for it — including on
          sites that added the markup by accident through a plugin.
        

      

    


    

      
How to use it

      
    
        
  1. Choose the type that matches the page. If the page is a product, choose Product; if it is your homepage, Organization or WebSite are usually the right pair.
    2. 
        
  2. Fill in the name and URL first. Everything else is optional, and the notes tell you which properties Google expects for the type you picked but could not find.
    3. 
        
  3. Add the same-as profile links for an Organization or a Person. They are how a search engine connects the page to a known entity rather than treating it as a new one.
    4. 
        
  4. Copy the JSON-LD into your page inside a <script type="application/ld+json"> tag, then test the live URL in Google's Rich Results Test before you consider it done.

Frequently asked questions

      

        

          Does schema markup improve my rankings?
          

            Not directly. Structured data does not change where a page ranks, and Google has said so
            plainly. What it changes is how the page can be displayed: with stars, prices, breadcrumbs
            or an FAQ dropdown in the result. Those rich results often earn more clicks at the same
            position, which is a real benefit — just a different one from ranking higher.
          

        

        

          Which schema type should I use?
          

            The one that describes what the page actually is. A product page takes Product, a page
            about your company takes Organization, a blog post takes Article. Google only grants rich
            results for the types it supports, so check its search gallery before investing in markup
            for an unusual type. Describing content that is not on the page is a guidelines violation,
            not a shortcut.
          

        

        

          How do I add the JSON-LD to my page?
          

            Paste it inside a script tag with type application/ld+json, in the head or the body —
            Google reads it wherever it appears. Then test the URL in Google's Rich Results Test, which
            reports both syntax errors and the properties Google needed but could not find. Markup can
            be perfectly valid JSON and still do nothing if it is missing a required property.
