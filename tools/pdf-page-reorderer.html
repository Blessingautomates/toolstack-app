PDF Page Reorderer

Put the pages of a PDF in the right order — by editing a list that starts out already correct.

Click to choose a PDF, or drag & drop it

PDF only · processed in your browser, never uploaded

Filled in with the document's own order as soon as a file loads, so the usual jobs are small edits rather than typing the whole sequence from scratch.

List every page once for a straight reorder. List fewer and the rest are dropped, so the same box also extracts. List one twice and it is duplicated. The line above the buttons always tells you which of those you are about to get.

Done

What this tool does

This tool rebuilds a PDF with its pages in whatever order you specify. The pages themselves are copied across intact — fonts, images and vectors come with them — so the output is the original pages rearranged, not pictures of them, and nothing is re-encoded or softened along the way.

The interaction is built around the fact that most reordering jobs are small. When a file loads, the order box is filled in with the document's own sequence, so moving the cover to the front or swapping two pages is an edit to a list that is already right rather than a sequence you have to type out from memory and get exactly correct.

How to use it

  1. Drop in your PDF. The order box fills in with 1, 2, 3, … up to the page count.
  2. Edit the list. Move a number, or use Reverse the order for a scan that came out backwards, and Reset to original to start again.
  3. Watch the line under the box — it tells you whether the list is a straight reorder, an extract, or has a page listed twice.
  4. Press Rebuild PDF and the reordered document downloads immediately.

Common use cases

  • Reversing a scan

    A duplex scanner that fed pages back-to-front produces a document in exactly reverse order. One button fixes it.

  • Moving a cover page

    Put the title page or the signed signature page at the front where it belongs.

  • Swapping two pages

    Fix a document where pages 7 and 8 were printed in the wrong order.

  • Duplicating a page

    List the same page number twice to produce two copies of a form in one file.

Frequently asked questions

What happens if I list fewer pages than the document has?

The unlisted pages are dropped, so the result is also an extract. That is genuinely useful, but it is easy to do by accident — the line under the box says exactly how many pages you have listed out of the total, so you are not guessing.

Can I duplicate a page?

Yes. List its number twice and it appears twice in the output. The hint line warns you that a page is listed more than once so you know it was intentional.

Does this change the files I already have?

No. Your original is never modified — it is read by the browser and a brand new PDF is generated and downloaded alongside it. If the result is wrong, nothing has been lost.
