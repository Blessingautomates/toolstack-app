What this tool does

Every video on YouTube and Vimeo has a set of thumbnail images at fixed addresses. This tool works out those addresses from the link you paste and lays the available sizes side by side, so you can see the maximum, high and medium versions, compare them, and save the one you want. Nothing is scraped and nothing is stored — the images are served directly by the platform, and your browser does the fetching.

Knowing the limits saves confusion. YouTube only generates its 1280×720 maximum-resolution image for videos uploaded at 720p or above, so on an older or low-resolution upload that size does not exist and the tool quietly falls back to 480×360. Downloading is also subject to the platform's CORS policy, so on some setups the save button opens the image in a new tab rather than saving it directly — that is a browser rule, not a fault in the tool.

How to use it

  1. Paste the full video URL — a youtube.com/watch?v= link, a youtu.be short link, or a Vimeo video URL.
  2. Press Enter or click Get Thumbnails. A bare 11-character YouTube ID also works if you already have one.
  3. Check the maximum-resolution preview. If the video is older, it will already have dropped to the next size down — the HD and medium frames below are always available.
  4. Click the download button under the size you want. If the browser opens the image in a new tab instead, right-click it and choose Save image as.
  5. Rename the file before you file it — the platform's filenames are long and similar.

Frequently asked questions

Is it legal to download someone else's thumbnail?

The image is copyrighted by the video's creator, and downloading it does not transfer any rights to you. Personal reference, mood boards and research are normally fine. Republishing it on your own video, site or thumbnail is not, unless you have the creator's permission or a licence. If in doubt, ask — most creators say yes.

Why does the maximum-resolution thumbnail fall back to a smaller one?

YouTube only generates the 1280×720 maxresdefault image for videos uploaded in 720p or higher. For older or low-resolution uploads that file simply does not exist, so the tool detects the failure and shows the 480×360 high-quality image instead of a broken frame.

What if the download button opens the image in a new tab instead?

YouTube serves thumbnails without a CORS header, so the page cannot always read the bytes to save them directly. When that happens the tool opens the full-size image in a new tab, where you can right-click and choose Save image as. The result is identical.
